Sobre

Pré-requisitos

O SAVIT evoluiu: agora é um projeto de Realidade Aumentada (AR) rodando diretamente no mobile. Para testar/desenvolver, você vai precisar:

  • Celular compatível com AR (ARCore/ARKit) e câmera funcionando.
  • Rede local (celular e servidor na mesma rede) para comunicação via HTTP.
  • Python (IA exposta via servidor HTTP, acessado pelo celular) para detectar/interpretar movimentos e movimentar as peças.

Funcionamento

O jogo roda em AR no celular e se comunica com uma IA em Python via HTTP para ajudar no controle/movimentação das peças. No Unity, também usamos o MediaPipe (biblioteca integrada no projeto) para leitura/apoio dos movimentos.

MediaPipe utilizado (UPM/Git, tag v0.16.3): pacote (referência).

Repositório atual (AR): Orbi-SP/savit-AR.
Projeto anterior (3D): Orbi-SP/savit-game.

Futuro

Implementações futuras planejadas:

  • Realizar a montagem do computador por completo (fonte, processador, HD/SSD etc.).
  • Melhorar a experiência em AR (precisão, performance e estabilidade no mobile).
  • Melhorar/empacotar a IA em Python e a comunicação via HTTP (setup mais simples).
  • Acompanhamento das atividades conforme avanço em módulos dentro do game.
